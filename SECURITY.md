# Security

Report a vulnerability by email to son@metacraft.studio, not in a public issue. Include the program id or the file, the steps or the transaction that show it, and what an attacker gains.

In scope: the on-chain program in `program/` at the devnet id in `README.md`, the services in `tools/chain/`, and the Seeker app in `android/` and `native/`. Mainnet is not live. The limits we already know are listed under "Trust model and known limits" in `README.md`.
