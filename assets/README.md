# assets

Runtime assets loaded by the renderer (`native/`) and bundled into the APK (`android/`). Generated from `art/`; do not edit by hand.

```
pets/          pet meshes and baked animations (.glb)
environment/   burrow, campfire, props, harvest objects (.glb)
palettes/      palette LUTs (.png)
```

See `art/README.md` for the export rules.
