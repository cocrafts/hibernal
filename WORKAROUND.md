# Workarounds in the std/solana port

Each row is a place where Hibernal goes around a gap instead of waiting for its root fix. Removing a row means doing what its last column says.

| Where | Workaround | Root fix | Remove when |
|---|---|---|---|
| every build of `program/` | built with the private `/Users/le/metascript/.hibernal-msc/bin/msc` (BUILD `5828f9e7` = recompiler `36251885` + lane A `bca987c4` + std/solana `851d8bd2`, branch `wt/hibernal-msc`, never landed); `~/.metascript` stays `013853dd` | the same commits land on recompiler `main` and are synced to `~/.metascript` | the installed `msc` contains them: build with plain `msc`, delete `/Users/le/metascript/.hibernal-msc` |
